# OtzyvTut Engine

**v1.2:** во вкладке «Отзывы из сети» добавлены источники moshennik.eu (чёрный список мошенников: поиск по названию и карточки), jobs.dou.ua (отзывы сотрудников IT) и otzovik.com (по прямой ссылке). Всего источников шесть: vidhuk.ua, minfin.com.ua, vnutri.org, moshennik.eu, dou.ua, otzovik.com.

Программа управления сайтом отзывов **otzyvtut.com**: собирает факты о компаниях с открытых площадок, пишет редакционные тексты через Google Gemini, публикует карточки на сайт и проверяет активность компаний. Интерфейс — одна веб-страница на русском, всё видно и понятно.

## Установка и запуск

Нужен Python 3.10+.

```
pip install -r requirements.txt
python app.py
```

Откроется адрес **http://127.0.0.1:8790** — введи его в браузере.

Windows: двойной клик по `run.bat`. Linux/Mac: `./run.sh`.

## Первый запуск: Настройки

Вкладка «Настройки»:

1. **API-ключ Google Gemini** — получи бесплатно на https://aistudio.google.com/apikey и вставь сюда.
2. **Логин и пароль админки WordPress** сайта otzyvtut.com.

Настройки хранятся только на твоём компьютере (`data/settings.json`) и никуда не передаются, кроме самих сервисов.

## Как работать

1. **Парсер** — выбери нишу (финансы, крипто, курсы, магазины, агентства) и количество. Программа соберёт карточки компаний: название, описание, рейтинг и число отзывов на внешней площадке, просмотры. Компании с подозрительно «идеальной репутацией» отмечаются отдельно.
2. **Очередь и тексты** — отметь карточки и нажми «Написать обзоры» или «Написать описания»: Gemini напишет редакционные тексты по фактам. Затем «Создать на сайте (черновики)» — карточки появятся на сайте невидимыми; «Опубликовать выбранные черновики» — когда проверишь. «Экспорт в файл» — сохранить строки импорта для ручной вставки в плагин.
3. **Отзывы из сети** — экран мониторинга: введи название компании или ссылку на её карточку на vidhuk.ua, minfin.com.ua или vnutri.org — программа соберёт на один экран все отзывы о ней (клиентов и сотрудников): автор, оценка, дата, текст, источник. Плюс сводка: средний рейтинг по всем площадкам, доля негатива, всплески по датам, повторяющиеся тексты, главные слова жалоб и кнопка «Сводка Gemini по жалобам». Собранное — аналитика, оно никуда не публикуется.
4. **Активность компаний** — вставь сайты компаний списком, программа проверит, кто жив и работает в 2025–2026.
5. **Обзор в карточку** — добавить готовый обзор в уже существующую карточку сайта по её ID.

## Что программа делает и чего не делает

- Тексты пишутся **от имени редакции** по собранным фактам: описания компаний и обзоры «Обзор редакции OtzyvTut».
- Программа **не создаёт отзывы от имени посетителей** и не переписывает чужие отзывы в ленту — это осознанное ограничение движка.

## Требования к сайту

Для публикации нужен активный служебный плагин «Bulk Review Moderation (Otzyvtut)» в админке WordPress (он уже установлен на otzyvtut.com).

## Файлы

- `app.py` — сервер и веб-интерфейс
- `engine/` — модули: `parser.py` (донор), `gemini.py` (тексты), `publisher.py` (WordPress), `activity.py` (проверка сайтов), `categories.py` (ниши и категории), `store.py` (очередь, настройки, журнал)
- `data/` — рабочие данные программы (создаётся автоматически)
