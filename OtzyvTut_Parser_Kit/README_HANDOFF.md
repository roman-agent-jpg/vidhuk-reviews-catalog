# OtzyvTut — парсер донора vidhuk.ua: комплект передачи

Инструмент, которым наполнялся каталог сайта отзывов **otzyvtut.com** (WordPress, кастомная тема reviews-theme, карточки — post_type `companies`, категории — таксономия `company_categories`).

## Файлы комплекта

| Файл | Что это |
|---|---|
| `vidhuk_parser.py` | Парсер v2. Обходит карточки vidhuk.ua из карты сайта, вытаскивает по JSON-LD: название, рейтинг, число отзывов; описание — из блока `#descr` (полное, с гардами от сайдбар-мусора и JS-обрывков; короче 60 символов = стаб, описание не берётся). Дедуп по нормализованному названию против дампа OtzyvTut и уже собранных кандидатов. |
| `build_import.py` | Генератор пачек импорта из пулов кандидатов: сначала детектор-A (рейтинг ≥4.8 и ≥20 отзывов), затем по просмотрам; файлы по 40 строк; кросс-дедуп и DENY-лист (ликвидированные банки, физлица, мусор донора). |
| `vidhuk_sitemap_organizations_2026-10-20.xml` | Полная карта сайта донора (55 350 URL) на 2026-10-20. |
| `candidates_mfo.jsonl` / `candidates_courses.jsonl` / `candidates_invest.jsonl` | Разобранные пулы: финансы/МФО — 248, курсы/школы — 248, инвест/крипто — 137 карточек (факты без текстов отзывов). |
| `candidates_raw.jsonl` | Сырой первый проход парсера. |
| `import_*.txt`, `import_*_report.md` | Уже импортированные на сайт пачки и отчёты по ним. |
| `test_import_25.txt` | Первая тестовая пачка (25 карточек). |
| `parser_*.log` | Логи прогонов парсера. |
| `otzyvtut.sql` | Дамп базы OtzyvTut от 2026-10-20 (источник дедупа по названиям существующих компаний; ~215 МБ). |

## Что уже сделано на сайте (НЕ повторять)

Импортировано и опубликовано **294 карточки** — все они есть в `import_*.txt` и `test_import_25.txt`. Повторный импорт тех же названий плагин отсечёт как дубли, но время на это тратить не надо: бери из пулов только те компании, которых нет в import-файлах.

## Формат импорта на сайт

Импорт делается служебным плагином WordPress «Bulk Review Moderation (Otzyvtut)» (страница «Модерация пачками» в админке), блок «Импорт карточек компаний». Формат строки:

```
Название ||| term_id категории ||| Описание
```

Максимум 40 строк за раз. По умолчанию создаются черновики; публикация — отдельным шагом по списку ID тем же плагином.

Категории (term_id): 13 — банки, 17 — доставка, 18 — другое, 24 — магазины, 42 — агентства трудоустройства за границей, 45 — интернет-магазины, 47 — IT компании, 48 — биржа/крипто, 50 — микрозаймы, 83 — курсы и онлайн-школы.

## Как запускать парсер у себя

В начале `vidhuk_parser.py` константы `BASE`, `SITEMAP`, `DUMP` указывают на исходные пути рабочей папки — поправь под своё расположение файлов. Зависимости: Python 3 + curl в PATH (запросы идут через curl с браузерным User-Agent, режим мягкий, с задержками). Ключей и доступов комплект не содержит.

## Аналитика базы (папка `db_analysis/`) и документы (папка `docs/`)

Скрипты, которыми разбирался дамп OtzyvTut и готовились рабочие выборки: `analyze.py` (общий разбор базы) + `ANALYSIS_SUMMARY.md` и `analysis_2026-10-20.json`; `activity_extract.py` (фильтр активных компаний) → `docs/active_targets.md` + `activity_rows.json`; `stagec_classify.py` (классификация черновиков) + планы/результаты; `top10_extract.py` (данные топ-10 карточек); `warm19_extract.py` (выборка плативших за скрытие компаний). В `docs/` также: `perfect_reputation_detector.md` — методика детектора «идеальной репутации», `final_targets_2026-10-21.md` — проверенные активные цели, `warm19_sheet.md` — тёплые компании с контактами из карточек.

## Обновлённая программа (папка `engine/`)

В комплект включён полный исходник программы **OtzyvTut Engine v1.3** — развитие этого парсера в виде локальной веб-панели (Python, `python app.py`, порт 8790):

- `engine/parser.py` — тот же сбор фактов с vidhuk.ua (кэш карты сайта само чинится при первом запуске);
- `engine/reviews.py` — мониторинг отзывов с **шести** источников: vidhuk.ua, minfin.com.ua, vnutri.org, **moshennik.eu** (чёрный список мошенников; поиск по названию, отметка «против» = оценка 1), **jobs.dou.ua** (сотрудники, подтверждённые аккаунты), **otzovik.com** (по прямой ссылке); сводка со всплесками, дублями, словами жалоб;
- **детектор разрыва рейтингов** (`gap_detector` в reviews.py): источники помечены по строгости, сравниваются средние мягких площадок с модерируемыми и долей «мошенник» на moshennik; сильный/заметный сигнал подсвечивается в интерфейсе. Сигнал внутренний, не публичное обвинение;
- остальные модули: генератор обзоров Gemini, публикатор в WordPress, проверка активности компаний, панель `ui.html`, настройки в `data/` (в комплекте пустые — ключи и пароли принимающий вводит сам в интерфейсе программы).

## Принципиальное ограничение

Парсер собирает **факты о компаниях** (название, описание деятельности, рейтинг, счётчики). Тексты чужих отзывов в комплект и в импорт не входят и на сайт как отзывы не переносятся.
