# Детектор «слишком идеальной репутации» — метод поиска платящих компаний (идея Романа, 2026-10-20 22:44)

## Гипотеза
Компании с неестественно идеальной репутацией на отзовиках, скорее всего, уже платят за репутацию (заказные положительные отзывы и/или зачистку негатива). Это самые тёплые лиды для платного удаления негатива на otzyvtut: они уже понимают ценность репутации и уже тратят на неё деньги.

## Признаки и скоринг (0–100, считать по данным доноров)
1. **Аномалия рейтинга:** средняя оценка ≥ 4.8 при ≥ 30 отзывах → +25
2. **Нет негатива:** доля оценок 1–2★ < 2% (у живых сервисных компаний норма 10–20%) → +20
3. **Всплески:** > 40% отзывов в любом 30-дневном окне, пачки в один день → +15
4. **Шаблонные тексты:** короткие, одинаковая структура, общие слова без конкретики (дат, имён, номеров заказов), повторяющиеся фразы → +10
5. **Авторы-одноразки:** много авторов с единственным отзывом, зарегистрированных в один период → +10
6. **Разрыв между площадками:** оценка отличается на ≥ 1.0 звезды между сайтами (5.0 на одном, 3.4 на другом) → +15. Сильнейший признак: негатив где-то есть, просто на «чистой» площадке его нет.

Пороги: **≥ 60 — список A** (почти наверняка платит за репутацию — приоритетные лиды); 40–59 — наблюдение; < 40 — обычные.

## Источники данных
- vidhuk.ua (рейтинг, кол-во отзывов, просмотры, тексты и даты отзывов — для признаков 1–5)
- Minfin/Finance.ua (банки/МФО), Hotline (магазины) — второй источник для признака 6
- Собственный каталог otzyvtut (после разбора дампа) — у кого из них уже есть карточка и какой там реальный рейтинг

## Как применяем
1. Парсер донора собирает компании + агрегаты отзывов → считаем скор.
2. Список A сверяем с каталогом otzyvtut: кого нет — **импортируем карточки первыми** (такие компании мониторят свою репутацию и сами найдут свою карточку у нас).
3. Список A = готовый список для предложения услуги удаления негатива (страница /removing-reviews/ после этапа F).
4. Ниши с самым дорогим чеком, где репутацию покупают чаще: МФО и банки, медицина/стоматология, юристы, застройщики, автосервисы и ремонт, инфобизнес/курсы, клининг/переезды.

## Граница (важно)
Скор — это подозрение для внутреннего приоритета, а НЕ доказательство. Публично обвинять компанию в покупке отзывов нельзя (клевета, иски) — наружу метод не выносим, используем только как внутренний скоринг лидов.
